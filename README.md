# Notational (Legacy HTML)

This branch preserves the **original single-file** Carnatic music notation app — one `index.html` with vanilla JavaScript, no build step required.

> **The current app lives on [`main`](../../tree/main)** (Next.js + React + TypeScript). Use that branch for development and deployment.

## Quick start

Open `index.html` in a browser, or serve it locally:

```bash
python3 -m http.server 8080
# then visit http://localhost:8080
```

## What's included

- Swara/sahitya notation grid with full 35-talam system
- Section headings, playback simulation, JSON save/load
- Firebase cloud accounts (configure in the file's `firebaseConfig`)
- Dark mode and print styles
